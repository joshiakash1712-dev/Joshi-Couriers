# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or rule weakness in the Joshi Couriers application, please do not open a public issue.

Instead, please send an email directly to the primary administrators:
- **Akash Joshi**: [joshiakash1712@gmail.com](mailto:joshiakash1712@gmail.com)
- **Alternate**: [joshiakash1209@gmail.com](mailto:joshiakash1209@gmail.com)

Please provide:
1. Detailed description of the vulnerability.
2. Steps to reproduce or proof-of-concept payload.
3. Impact assessment.

We take security seriously and will acknowledge your report within 48 hours.
